P3 交互手感 待手测

这一阶段决定"用起来像不像原来那个程序"，也是最容易被低估的一块。

  • 平滑滚动：用 ChangeView / ScrollPresenter 复刻 0.5 倍率缓动
  • 拖拽排序：WinUI 的 DragDrop 与 WPF 完全不同，需重写命中判定与插入指示线
  • 图标渲染：byte[] → BitmapImage，含首帧占位与异步补齐
  • 虚拟化调优：实测实例化数量，必要时换 ItemsRepeater + UniformGridLayout
  • 动画：页面切换、选中指示、面板滑入，改用 Composition 或内置转场
估时 1–2 天状态 已实现，拖拽与滚动手感需人工确认

风险登记

风险影响应对
平滑滚动需从零重写中WPF 的 Behavior 机制在 WinUI 不存在；P3 单独排期，不行就退回系统默认滚动
拖拽排序 API 差异大中WPF 用 DragOver/Drop + 自定义插入线；WinUI 用 DragStarting/Drop 且需 CanDrag 配置，P3 先做最小可用
Mica 仅 Win11 可用低README 声明支持 Win10 1809+，Win10 上降级为纯色背景，代码里按版本判断
WASDK 版本迭代快中锁 2.6.5，不跟预览版；升级单独排期并回归
双项目并存期间 CI 混乱低WinUI 放子目录，根目录 dotnet build 仍只命中 WPF 项目；CI 加独立 job
已定：接受体积从 63 MB 涨到 92 MB；卡片区按现版本还原；业务层不重写。 未定：侧边栏与标题栏两项，定了才能进 P1。
